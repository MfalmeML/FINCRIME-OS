# FINCRIME OS

Autonomous Real-Time Financial Crime Intelligence & Adaptive Decision Platform.

## The nine questions this platform answers

1. Is something suspicious happening?
2. How risky is it?
3. Is this an isolated event or part of a criminal network?
4. What should we do?
5. Should we inconvenience the customer?
6. Which cases should humans investigate?
7. What did the investigation discover?
8. Has the fraud pattern changed?
9. How should the system adapt?

## Optimization target

Minimize (Fraud Loss + False Positive Cost + Customer Friction + Investigation Cost)

Subject to: Authorization latency < 100 ms.
